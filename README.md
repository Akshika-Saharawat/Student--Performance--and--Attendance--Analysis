# Student Performance and Attendance Analysis

**Name:** Akshika  
**GitHub Repository:** https://github.com/Akshika-Saharawat/Student--Performance--and--Attendance--Analysis

## Overview
A Python-based data analytics project to analyse student performance, attendance, study hours, and examination scores.

## Objective
To load, clean, and explore student academic records and identify patterns between attendance, study hours, and exam scores.

## Technology
- Python
- Google Colab
- NumPy
- Pandas
- GitHub

## Dataset
- **File:** `dataset.csv`
- Contains student records including attendance, study hours, and examination performance factors.

## How to run
1. Open the repository on GitHub (`main` branch).
2. Open `Student_Performance_Analysis.ipynb` in **Google Colab** (or install required libraries locally using `pip install -r requirements.txt`).
3. Ensure `dataset.csv` is uploaded to the working directory.
4. Run all code cells sequentially from top to bottom.
